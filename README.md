# Celebrate Animation

An interactive celebration animation web page featuring confetti, fireworks, streamers, and synthesized handclap audio.

## Features

- Bilateral confetti burst (150 pieces from both sides)
- Animated fireworks using Web Animations API
- Gold streamers shooting from edges
- Synthesized handclap sounds via Web Audio API (no audio files needed)
- Animated congratulatory message with pulsing effect

## Technologies

| Technology | Usage |
|------------|-------|
| HTML5 | Page structure |
| CSS3 | Animations, gradients, keyframes, transitions |
| JavaScript (ES6+) | DOM manipulation, Web Audio API, Web Animations API |

## How to Use

Open `index.html` directly in any modern browser. Click the **Celebrate!** button to trigger the celebration effects.

## Browser APIs

- **Web Audio API** — Procedural handclap sound synthesis
- **Web Animations API** — Firework burst animations
